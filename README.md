# Eigeneyes supplementary data

Data associated with the paper "Eigeneyes: A statistical model of whole-eye geometry and its applications".

This repository contains the data used to generate Figures 5, 6 and 7 of the manuscript, provided in both MATLAB (`.mat`) and Excel (`.xlsx`) formats.

## Files

- `Figure_5_correlation_age_axial_length.mat/.xlsx`  
  Data used for the analysis of the relationships between Eigeneye coefficients, age and axial length.

- `Figure6_models_rmse_comparison.mat/.xlsx`  
  RMSE values used to compare the representation accuracy of the Eigeneyes models and the classical 8-PAR and 16-PAR geometric descriptions.

- `Figure7_Synthetic_dataset_quantification.mat/.xlsx`  
  Quantified biometric parameters from the synthetic datasets generated for different combinations of age and axial length.

The `.mat` files are intended for MATLAB users, whereas the `.xlsx` files provide the same data in spreadsheet format.# Eigeneyes-A-statistical-model-of-whole-eye-geometry-and-its-applications
